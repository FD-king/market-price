# বাজার দর (BazarDor)

### A Smarter Way to Track and Compare Everyday Market Prices

**বাজার দর (BazarDor)** is a web-based platform designed to help users explore, compare, and keep track of everyday product prices. It aims to make market price information more accessible and convenient, helping users make informed purchasing decisions.

## 🚀 Technologies Used

- **Next.js** – React framework for building the web application.
- **npm** – Package management and dependency installation.
- **Marquee** – For scrolling announcements and dynamic content.
- **HeroUI** – UI components for building a modern interface.
- **daisyUI** – Tailwind CSS component library for styling.
- **React Icons** – Icon library for React components.
- **Iconify** – Collection of icons from multiple icon sets.
- **Better Auth** – Authentication and user account management.
- **MongoDB** – Database for storing application data.
- **React Hot Toast** – Toast notifications for user feedback.

## ✨ Key Features

1. **Product Price Tracking**  
   Explore everyday products and view their listed market prices in one convenient place.

2. **Price Comparison**  
   Compare product prices to make better and more informed purchasing decisions.

3. **User Authentication**  
   Secure account registration and login with email/password, Google, and GitHub authentication.

4. **Personalized User Profiles**  
   Manage your account and access your personal information through a dedicated profile section.

5. **Responsive and User-Friendly Interface**  
   Enjoy a clean, accessible interface designed to provide a smooth experience across desktop and mobile devices.
